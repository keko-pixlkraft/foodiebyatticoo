# Local language flags

The GB, DE and ES SVGs are the unmodified 4:3 flags from `lipis/flag-icons`, downloaded on 2026-11-23. The upstream MIT license is included in `LICENSE`.

Source: https://github.com/lipis/flag-icons/tree/main/flags/4x3

These are presentation assets only. Language labels and behavior are supplied by the application independently of the flags. The English control uses the UK flag as requested.
